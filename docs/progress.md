## 数据工作流(SOP)

- 新增植物 → 写 `scripts/additional-plants.json`(必填 `chineseName`+`category`)→ `npm run import:plants` 校验/去重/合并 → `git commit`。
- 联网检索学名/别名 → 见 `plant-data-sop.md`(KEW POWO / RHS / 植物智 iPlant / 中国植物志 等)。
- Excel 导入已停用(2026-08-27)。
